# 运营数据分析案例（operations-data-analysis）

> 用数据回答运营问题：每个案例包含「背景 → 指标口径 → 分析过程 → 结论建议 → 验证方案」的完整闭环，而不是只堆图表。

## 🎯 这个仓库展示什么

运营岗最常被考察的数据能力不是跑模型，而是：

1. **定义口径**：同一个「参与率」，十个人有十种算法，先把口径说清楚
2. **拆解问题**：从「出席率低」拆到「哪个环节、哪类活动、什么原因」
3. **结论落地**：每条建议说清预期收益、成本和验证方式
4. **诚实标注**：数据来源、局限性和不可下结论的地方

## 🛠 复现方法（Excel）

1. 下载 `data/活动数据_模拟.csv`，用 Excel 打开
2. 新建计算列：
   - 报名率 `=报名数/曝光量`
   - 出席率 `=参与数/报名数`
   - 人均互动 `=互动数/参与数`
   - 分享率 `=分享数/参与数`
   - 次日回访率 `=次日回访数/参与数`
3. 选中数据区域 → 插入 → 数据透视表：行放「活动形式」，值放各比率字段（平均值）→ 即可复现报告第四节的分组对比
4. 选中「活动ID + 报名率」插入条形图，选中漏斗各级总量插入漏斗图，即可得到报告第三、四节的图表

## 📌 方法论：运营数据复盘的五步框架

```
① 明确问题   这次复盘要回答的业务问题是什么？（不是"看看数据"）
② 定义口径   每个指标怎么算、分母是谁、窗口多长，先写清楚
③ 拆解对比   总量 → 分组（类型/渠道/时间）→ 定位异常组
④ 解释归因   异常组有什么和其他组不同的机制？区分"相关"和"因果"
⑤ 建议验证   每条建议附上预期指标变化 + 最小验证实验
```
